# Malha municipal — Mato Grosso

- `mt_municipios.geojson`: municípios de MT (~1,4 MB) com propriedade `id` = código IBGE (7 dígitos).
- Fonte: [tbrugz/geodata-br](https://github.com/tbrugz/geodata-br) (`geojs-51-mun.json`).
- Usado pelo dashboard em **Territórios prioritários → Municípios e mapas** (coroplético por IBGE).

Não versionar shapefiles nacionais completos.
